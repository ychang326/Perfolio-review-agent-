# Performance Metrics Glossary

## Absolute P&L
Profit or loss in currency terms over a period (day, month, YTD, custom).

## Return %
P&L relative to starting value or invested capital for the period. Confirm the denominator used by the reporting system.

## TWR (Time-Weighted Return)
Removes the impact of external cash flows. Useful for comparing manager/strategy performance.

## XIRR / MWR (Money-Weighted Return)
Reflects the client's actual cash-flow timing. Useful for "how did *my* money do".

## Day P&L
Mark-to-market change for the current day. May exclude unsettled trades depending on policy.

## Reporting hygiene
- Always state the **period** and **method** when quoting performance.
- Do not invent TWR/XIRR if the data source did not compute them.
- Gross vs net of fees should be labeled when available.
