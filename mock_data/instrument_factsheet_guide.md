# Instrument Factsheet Reading Guide

A factsheet summarizes an instrument's objective, asset class, benchmark, and key risks.

## Typical sections
- **Title / identifier** — name and instrument id
- **Summary** — what the instrument is designed to provide
- **Asset class / sector**
- **Benchmark** — reference index if applicable
- **Risk disclosure** — mandatory caution language

## Assistant behavior
- Resolve tickers via instrument search, then fetch the factsheet tool.
- Do not invent benchmarks or disclosures.
- Factsheets are educational; they are not a recommendation to buy or sell.
